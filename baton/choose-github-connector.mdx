C1 offers three GitHub connectors. Each one is a separate connector with its own setup and its own set of capabilities:

- **[GitHub](/baton/github)**: organizations on `github.com`.
- **[GitHub Enterprise](/baton/github-enterprise)**: GitHub Enterprise Server (GHES) and GitHub Enterprise Cloud (GHEC), with enterprise-level features.
- **[GitHub Enterprise Cloud](/baton/github-enterprise-cloud)** (beta): an entire GHEC enterprise through one connector.

Use the decision guide below to pick one, then follow the setup instructions on that connector's page.

## Decision guide

<Steps>
  <Step title="Where is your GitHub environment hosted?">
    - **GitHub Enterprise Server (self-hosted, on your own domain):** use **[GitHub Enterprise](/baton/github-enterprise)**. It's the only connector that supports GHES.
    - **Organizations on `github.com` that aren't part of an enterprise account:** use **[GitHub](/baton/github)**.
    - **GitHub Enterprise Cloud:** all three connectors can work. Continue to the next step.
  </Step>
  <Step title="Do you want one connector for the whole enterprise?">
    The **[GitHub Enterprise Cloud](/baton/github-enterprise-cloud)** connector syncs every organization in the enterprise through one connector. To use it, you must be able to install one GitHub App on the enterprise and on each of its organizations. It's the only connector that syncs and provisions enterprise teams and invites users at the enterprise level.

    The GitHub and GitHub Enterprise connectors work per organization instead. With a personal access token, one connector can sync several organizations. With a GitHub App, you need one connector per organization.
  </Step>
  <Step title="Which capabilities do you need?">
    Check the [comparison table](#compare-the-connectors) for the capabilities you need. In particular:

    - **Enterprise roles, Enterprise Owner provisioning, licenses, or member last activity:** use **[GitHub Enterprise](/baton/github-enterprise)**.
    - **Fine-grained personal access tokens:** use **[GitHub](/baton/github)**.
    - **Personal access token authentication, organization roles, account deletion, or secrets and non-human identities:** use **[GitHub](/baton/github)** or **[GitHub Enterprise](/baton/github-enterprise)**. The GitHub Enterprise Cloud connector doesn't support these.
  </Step>
  <Step title="Does your enterprise use Enterprise Managed Users (EMU)?">
    All three connectors sync existing EMU users and govern their access, but none of them can create EMU accounts. See [Enterprise Managed Users](#enterprise-managed-users-emu) below.
  </Step>
</Steps>

### What only each connector offers

- **GitHub:** fine-grained personal access token authentication.
- **GitHub Enterprise:** GitHub Enterprise Server support, enterprise roles and Enterprise Owner provisioning, licenses, and member last activity.
- **GitHub Enterprise Cloud:** one connector for the whole enterprise, enterprise teams, and enterprise-level invitations.

## Beta status of GitHub Enterprise Cloud

The [GitHub Enterprise Cloud](/baton/github-enterprise-cloud) connector is in **beta**. If you need a capability it doesn't cover yet, use the GitHub or GitHub Enterprise connector instead.

## Enterprise Managed Users (EMU)

None of the GitHub connectors can create accounts for Enterprise Managed Users. With EMU, your identity provider (IdP) creates accounts on GitHub through SCIM, and GitHub doesn't allow managed users to be invited.

- **To create EMU accounts**, set up account creation in your IdP's GitHub SCIM integration, not in a C1 connector.
- **All three connectors sync existing EMU users** and govern their access: organization, team, and repository access, plus enterprise roles or enterprise teams on the connectors that support them.
- **Account provisioning from C1 fails for EMU:**
  - **GitHub and GitHub Enterprise:** the organization invitation fails with an error saying that the organization uses Enterprise Managed Users and that accounts are provisioned by the IdP.
  - **GitHub Enterprise Cloud:** the enterprise invitation fails with an error from GitHub.
