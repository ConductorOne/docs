## Gather Aws China credentials

<Warning>
To configure the Aws China connector, you need administrator permissions in Aws China.
</Warning>

<Steps>
  <Step>
    Sign in to the AWS China console and open **IAM**.
  </Step>

  <Step>
    Create an IAM user for C1 and grant it the read permissions listed in the [AWS connector](/docs/baton/aws-v2) documentation. To provision accounts, group memberships, policies or permission set assignments, also grant the write permissions documented there (for example the optional `IAMUserAccountProvisioning` and `IAMPolicyProvisioning` statements). Because the connector uses an IAM user, use `arn:aws-cn` ARNs in any policy you copy from that page.
  </Step>

  <Step>
    Create an access key for the user. Copy the **Access key ID** and **Secret access key** and save them securely. AWS China connectors authenticate with this key instead of assuming a role.
  </Step>
</Steps>

## Configure the Aws China connector

<Tabs>
  <Tab title="Cloud-hosted">
    Follow these instructions to use a built-in, no-code connector hosted by C1.

    <Steps>
      <Step>
        In C1, navigate to **Integrations** > **Connectors** and click **Browse connectors**.
      </Step>

      <Step>
        Search for **Aws China** and click **Add**.
      </Step>

      <Step>
        Choose how to set up the new Aws China connector:

        - Add the connector to a currently unmanaged app
        - Add the connector to a managed app
        - Create a new managed app
      </Step>

      <Step>
        Set the owner for this connector.
      </Step>

      <Step>
        Click **Next**.
      </Step>

      <Step>
        Find the **Settings** area of the page and click **Edit**.
      </Step>

{/* AUTO-GENERATED:START - config-params
     Generated from config_schema.json. Do not edit manually. */}

      <Step>
        Enter the required configuration:

        - **Access Key ID**: The access key ID of the IAM user
        - **Secret Access Key**: The secret access key of the IAM user
        - **Region**: `cn-north-1` or `cn-northwest-1`
      </Step>

{/* AUTO-GENERATED:END - config-params */}

      <Step>
        Click **Save**.
      </Step>

      <Step>
        The connector's label changes to **Syncing**, followed by **Connected**. You can view the logs to ensure that information is syncing.
      </Step>
    </Steps>

    **Done.** Your Aws China connector is now pulling access data into C1.
  </Tab>

  <Tab title="Self-hosted">
    Follow these instructions to use the Aws China connector, hosted and run in your own environment.

    When running in service mode on Kubernetes, a self-hosted connector maintains an ongoing connection with C1, automatically syncing and uploading data at regular intervals.

    ### Step 1: Set up a new Aws China connector

    <Steps>
      <Step>
        In C1, navigate to **Integrations** > **Connectors** and click **Browse connectors**.
      </Step>

      <Step>
        Search for **Baton** and click **Add**.
      </Step>

      <Step>
        Choose how to set up the new Aws China connector:

        - Add the connector to a currently unmanaged app
        - Add the connector to a managed app
        - Create a new managed app
      </Step>

      <Step>
        Set the owner for this connector.
      </Step>

      <Step>
        Click **Next**.
      </Step>

      <Step>
        In the **Settings** area of the page, click **Edit**.
      </Step>

      <Step>
        Click **Rotate** to generate a new Client ID and Secret.

        Carefully copy and save these credentials.
      </Step>
    </Steps>

    ### Step 2: Create Kubernetes configuration files

    Create two Kubernetes manifest files for your Aws China connector deployment:

    #### Secrets configuration

    ```yaml expandable
    # baton-aws-china-secrets.yaml
    apiVersion: v1
    kind: Secret
    metadata:
      name: baton-aws-china-secrets
    type: Opaque
    stringData:
      # C1 credentials
      BATON_CLIENT_ID: <C1 client ID>
      BATON_CLIENT_SECRET: <C1 client secret>

      # Aws China credentials
      BATON_GLOBAL_ACCESS_KEY_ID: <access key ID>
      BATON_GLOBAL_SECRET_ACCESS_KEY: <secret access key>
      BATON_GLOBAL_REGION: cn-north-1
    ```

    Run `--help` to see all available configuration flags and environment variables.

    #### Deployment configuration

    ```yaml expandable
    # baton-aws-china.yaml
    apiVersion: apps/v1
    kind: Deployment
    metadata:
      name: baton-aws-china
      labels:
        app: baton-aws-china
    spec:
      selector:
        matchLabels:
          app: baton-aws-china
      template:
        metadata:
          labels:
            app: baton-aws-china
            baton: "true"
            baton-app: aws-china
        spec:
          containers:
          - name: baton-aws-china
            image: public.ecr.aws/conductorone/baton-aws-china:latest
            imagePullPolicy: IfNotPresent
            env:
            - name: BATON_HOST_ID
              value: baton-aws-china
            envFrom:
            - secretRef:
                name: baton-aws-china-secrets
    ```

    ### Step 3: Deploy the connector

    <Steps>
      <Step>
        Create a namespace in which to run C1 connectors (if desired), then apply the secret config and deployment config files.
      </Step>

      <Step>
        Check that the connector data uploaded correctly. In C1, click **Apps**. On the **Applications** tab, locate and click the name of the application you added the Aws China connector to. Aws China data should be found on the **Entitlements** and **Accounts** tabs.
      </Step>
    </Steps>

    **Done.** Your Aws China connector is now pulling access data into C1.
  </Tab>
</Tabs>
