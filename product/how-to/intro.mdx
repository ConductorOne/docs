Welcome! This section covers two different ways to learn C1, depending on what you need:

- **[Use cases](#use-cases)** — narrative walkthroughs of how C1's capabilities fit together to solve a specific problem, like onboarding or access reviews. Start here if you're new to C1, evaluating it, or want the bigger picture behind a workflow.
- **[How-to guides](#how-to-guides)** — step-by-step instructions for a specific task, like requesting access or completing a review. Start here if you already know what you need to do.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="What's the difference between a use case and a how-to guide?">
    A use case explains how a set of C1 capabilities work together to solve a problem — good for building a mental model or evaluating a workflow. A how-to guide walks through one specific task step by step. Use cases link out to the how-to guides and reference docs that cover their individual steps in depth.
  </Accordion>
  <Accordion title="What's the difference between a request and a review?">
    A request is something you ask for, like access to an app. A review is something you're asked to do, like confirming that a colleague's access is still appropriate as part of a [user access review campaign](/product/how-to/review-tasks). Both can show up as tasks that need your attention.
  </Accordion>
  <Accordion title="Why can't I see an app I need access to?">
    C1 admins control which apps and permissions you can see and request, based on your department or role. See [How to request new access](/product/how-to/create-requests) for more on how this works.
  </Accordion>
  <Accordion title="Why did my access change without me requesting it?">
    Someone with the right permissions — an approver, an admin, or an automated policy — can grant or revoke access on your behalf. Check [How to complete access change tasks](/product/how-to/access-change-tasks) if you're the one responsible for making that change for someone else.
  </Accordion>
  <Accordion title="How do I make sure I see task notifications?">
    C1 notifies you by email, Slack, or Microsoft Teams. Confirm your notification preferences on the [notification settings page](/product/admin/notifications-user-settings).
  </Accordion>
</AccordionGroup>
