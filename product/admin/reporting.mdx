## Create a report

Ask a reporting question in a conversation with C1AI — for example, "how many admin entitlement assignments do we have?" C1AI builds the report from your org's data.

To keep a report instead of letting it live only in that conversation, select **Save report** and give it a name and an optional description.

## View a saved report

A saved report's page shows when it was created, who created it, when it last ran successfully, and its current status.

<Frame>
<img src="/images/product/assets/saved-reports-1.png" alt="A saved report's detail page, showing its creation date, creator, last successful run, status, and a donut chart with a data table below it."/>
</Frame>

From here, you can:

- **Refresh** the report to re-run it against the latest data.
- **Edit with Report assistant** to adjust its parameters or change what it shows, in a conversation.
- Switch between the **Report** tab (the rendered result) and the **Function** tab to review the underlying logic and the sources behind the result, so every number traces back to where it came from.

## Find your reports

The **Platform > Reporting** page lists every report you've saved, so you don't need to search your conversation history to find one again. From the list, you can rename or delete a report.
